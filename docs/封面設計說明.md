# 封面設計說明（週報自動生成封面）

本檔完整記錄封面圖的**設計目標、演進、最終鎖定規格、關鍵字管線與上傳陷阱**。
封面是每期自動生成、掛上 Matters 草稿的視覺主體，設計經多輪打磨後**鎖定**——改動前務必讀完本檔。

> 程式：渲染在 `bot/collage.py`、關鍵字抽取在 `bot/cover.py` 的 `keywords()`。
> 串接在 `bot/digest.py` 的 `_make_cover()` → `_post_draft()`。

---

## 1. 設計目標（為什麼長這樣）

團隊要的是一張**有社區感、藝術質感、可完全自動化**的封面，具體原則：

1. **藝術拼貼，不幼稚**：撕貼紙質感的關鍵字卡片，像手作剪貼簿，而非扁平色塊或純文字排版。
2. **非 Matters 品牌色**：刻意用「非官方」色盤，讓週報自成一個視覺系列、與站方內容區隔。
3. **每期自動換字**：關鍵字**自動**從當期文章抽取，卡片內容每期不同、版式自動重排——零人工。
4. **關鍵字清楚、零豆腐字**：繁體、語意完整、字型渲染得出（見第 4 節管線）。

## 2. 演進（我們試過什麼、為何否決）

| 階段 | 做法 | 結果 |
|------|------|------|
| v1 | 關鍵字**雲圖**（字體大小依權重、四角星、線條裝飾） | 太像資訊圖表、不夠「作品感」，否決 |
| v2 | 扁平圓角色卡（chips） | 太平、像標籤雲，否決 |
| v3 | 滿版碎紙 patchwork（密集拼貼） | 「太花」，只想參考色彩不要滿版，否決 |
| **v4（定稿）** | **撕邊卡片拼貼**：撕紙背景塊＋半調網點＋撕邊關鍵字卡＋顆粒噪點 | 採用 |

> 舊雲圖的渲染函式（`bot/cover.py` 的 `generate` / `_star` / `_decor`）**已不再使用**，
> 僅保留 `keywords()` 供抽字。這些死碼日後可清理（見第 7 節）。

## 3. 最終鎖定規格（`bot/collage.py`）

**畫布**：1200×1200 RGBA；固定亂數種子 `random.Random(3)` → **同輸入必得同一張圖**（可重現、可回歸測試）。

**主題 `THEMES`（四套，皆非 Matters 品牌色）**：
| key | 用途 | 色調 |
|-----|------|------|
| `riso` | **週報（目前唯一使用）** | 孔版風：米紙底 ＋ 番茄紅／鈷藍／墨黑（背景塊加**半調網點**） |
| `coral` | 備選 | 暖珊瑚紅／粉／金黃 |
| `earthy` | 備選 | 沉穩青綠／芥末／鏽紅 |
| `vintage` | 備選 | 復古牛皮棕／鼠尾草綠／灰玫瑰 |

> 目前**只用 `riso`**（週報）；`coral`／`earthy`／`vintage` 保留為備選主題，暫未啟用。

每個主題定義：`bg`（底色）、`accent[2]`（背景撕紙塊）、`chips[5]`（卡片的 (底色, 字色) 配對，輪替使用）、`title`／`sub`／`logo`（三處文字/標誌色）。

**版面元素（由下而上疊）**：
1. **背景撕紙塊**：左上、右下各一塊半透明（alpha 40）撕邊多邊形（`_torn`）。
   `riso` 額外在塊內鋪**半調網點**（18px 間距、4px 圓點，遮罩貼齊塊形），做出孔版印刷感。
2. **碎紙屑 `_confetti`**：10 個小圖形（圓、空心圓、三角、旋轉長條、十字），點綴用。
3. **標題（kicker）**：左上 `(86, 96)`，字級 50、字重 800。
4. **關鍵字卡片**：`size_for(i)` → 前 2 字級 88（字重 800）、接 3 字級 62、其餘 50；
   過寬自動縮字。每張是**撕邊卡片**（主題 chip 配色、旋轉 −6°～+6°、輕微上下抖動），
   **層疊排版**（shelf-pack）成置中的多列、整體垂直置中。
5. **Matters logo**：左下 `(86, H−100)`，高 48，依主題 `logo` 色上色；
   `_logo_no_lab()` 用 alpha 欄間隙偵測**自動裁掉「Lab」字樣**，只留雙圓＋Matters。
6. **日期**：右下 `(1114, logo 中線)`，字級 32、字重 600、主題 `sub` 色，**與 logo 水平中線對齊**。
   顯示格式為 **`YYYY · MM · DD`**（`_make_cover` 把 ISO 日期的 `-` 換成 ` · `），日期取**香港時間**（`_today_hkt`, UTC+8）。
7. **顆粒噪點 `grain`**：`effect_noise` 疊一層（alpha 20），增藝術質感。

**字體**：`bot/assets/NotoSansTC.ttf`（可變字重，`set_variation_by_axes`）。

> **容錯（fail-open）**：`_make_cover` 用 `try/except` 包住整個「抽字＋渲染」，**任何例外只記 `log.warning`
> 並回傳 `None`**，草稿照發、只是沒有封面。故日後改關鍵字管線或渲染若丟例外，封面會**靜默消失**而非中止發稿
> ——除錯時看 log 的 `cover generation failed`。

## 4. 關鍵字抽取管線（`bot/cover.py` 的 `keywords()`）——品質關鍵

使用者要求：**準確、繁體、語意完整、零缺字**。管線：

1. **斷詞在簡體最準** → 先 `zhconv` 轉簡體，用 `jieba.analyse.extract_tags`（TF-IDF，`topK=5`，
   `allowPOS=_NOUN_POS`），再把**選中的詞轉回繁體**顯示（`_title_terms`）。
   - `_NOUN_POS` 實際集合 = `ns/nr/nz/nt/n/nl/ng/vn/l/i/j/s`——**不只純名詞**，還含動名詞 `vn`、
     習用語 `l`、成語 `i`、處所 `s` 等（日後調品質要照這份白名單改，別只當「名詞」）。
   - 為何用 TF-IDF：避免「龍山寺」被斷成「山寺」之類的破碎語意。
   - fallback：抽不到就取詞性首字為 `n/i/v/l/s` 的最長 token。
2. **一律繁體**：解決簡體缺字（如「馬來西亞」）在繁體字型渲染成「豆腐（⊠）」。
3. **字型覆蓋檢查**：用 `fontTools` 讀字型 cmap（`_covered`），**任何有缺字的詞直接丟棄** → 零豆腐字。
4. **篩選規則**：詞總長 **2–4 字元**且**至少含一個 CJK 字**（`_CJK` 只判斷「含不含 CJK」、**不計 CJK 數**，
   故如「AI技術」len==4 也會過）、非停用詞、不重複；**每篇標題最多取 2 詞**；全部最多 `k=12`。
   `_make_cover` 再取前 **10** 個交給渲染。

**每期關鍵字來源（使用者定案）**：
- **週報**：從當期熱門 10 篇（過去 7 日）抽。
- → 所以**每一期封面上的字都會換**（跟著當期文章走）。

> **關鍵字順序＝視覺層級（重要因果）**：`keywords()` 回傳的**順序**直接決定卡片大小
> （見第 3 節 `size_for`：前 2 大、接 3 中、其餘小），而順序來自標題的**輸入順序**——
> 即熱門排名（越熱門的字上越大卡）。**改關鍵字來源或排序 → 直接改變封面的視覺層級**。

## 5. 週報封面規格（定案）

| | 週報 |
|---|------|
| 主題 | `riso`（孔版紅藍） |
| kicker | `一週速報 ｜ 社群熱門文章` |
| 圖說（figcaption） | `圖中關鍵字由過去七日熱門文章自動擷取` |
| 關鍵字來源 | 10 篇熱門（7 日） |

> kicker **不含「Matters」**（因圖上已有 Matters logo）；文章**標題**才含 Matters 全名（見運維手冊）。

## 6. Matters 上傳兩個坑（血淚，務必保留）

1. **`singleFileUpload`（multipart）**要加 header **`apollo-require-preflight: true`**（＋ `x-apollo-operation-name`），
   否則被 CSRF 擋。`SingleFileUploadInput` **沒有 `mime` 欄位**（mime 由 multipart part 帶）。
2. 內文圖 `<figure class="image">` 內**必須有 `<figcaption>`**，否則 `putDraft` 解析崩潰
   （`Cannot read properties of undefined (reading 'firstChild')`）。
3. `AssetType` 用 `cover`／`embed`；`EntityType` 用 `draft`；回傳 `asset.path` 是完整 imagedelivery URL。
4. 封面同時：掛草稿 `cover` 欄位＋作為內文首圖 `embed`。內文首圖 HTML 為
   `<figure class="image"><img src="{embed.path}" data-asset-id="{embed.id}" alt=""><figcaption><span>圖說</span></figcaption></figure>`——
   `<img>` **必須帶 `data-asset-id`**（＝上傳回傳的 embed id），否則 embed 會與資產失聯；`src` 用回傳的完整 imagedelivery URL。

## 7. 改動指南 / 待清理

- **換週報主題色**：改 `bot/digest.py` 中 `_make_cover(..., theme="riso")` 的 theme，或在
  `bot/collage.py` 的 `THEMES` 調色。**版式（撕邊、網點、排版）已鎖定，勿亂改**。
- **調關鍵字品質**：改 `bot/cover.py` 的 `keywords()`（篩選長度、每篇取幾詞、停用詞）。
- **資產**：`bot/assets/NotoSansTC.ttf`（約 12MB）與 `matters-logo-white.png` **刻意入庫**
  （確定性、離線、CI 不必每次下載）。
- **待清理**：`bot/cover.py` 舊雲圖渲染函式（`generate`/`_star`/`_decor`）已無人呼叫，可移除以免混淆。
